Baseline reviewed: 2026-07-14. Before high-stakes or implementation-specific work, verify the latest official versions.

## Draft caution

The IETF Idempotency-Key header remains a draft in the reviewed baseline:
https://datatracker.ietf.org/doc/draft-ietf-httpapi-idempotency-key-header/

Do not present drafts, company style guides, or community conventions as universal standards. Record the selected profile and interoperability assumptions.
